# AI Radar

Невеликий каталог нових AI-проєктів: пошук, фільтри за нішею та авторитетом домену, добірка новинок і порівняння сайтів. Дані з публічного API [freeserp.ai](https://freeserp.ai/docs.php), індекс `index=sites` (головні сторінки сайтів), ніша AI.

Стек навмисно простий: чистий HTML, CSS і JS, без збірки та залежностей. Для тестового мені було важливіше, щоб проєкт запускався одразу і його можна було прочитати за вечір.

План сайту (мета, аудиторія, сторінки, структура) лежить у [PLAN.md](PLAN.md) і доступний в самому проєкті на сторінці `#/plan`.

## Що зроблено

- **Каталог.** Пошук, ніша, мінімальний DR, сортування, перемикач «лише справжні стартапи» (`ai_startups=1`), пагінація. На початку сторінки метрики індексу та панель «Щойно виявлені».
- **Новинки.** Період на 3, 7, 14 або 30 днів, фільтр за нішею, групування за датою.
- **Порівняння.** До чотирьох сайтів у таблиці, DR зі шкалою. Вибране зберігається в localStorage, унизу екрана є невелика панель вибраних сайтів.
- Фільтри лежать в адресі, тому посиланням можна поділитися. Є світла й темна теми, стани завантаження, порожньої видачі та помилки з повтором, мобільна та планшетна верстка.

## Запуск

Потрібен Node.js, `npm install` не треба:

```bash
cd ai-radar
node server.js
```

Далі http://localhost:8080. Подвійний клік по `index.html` не підійде: браузер блокує запити зі сторінок `file://`.

Для деплою достатньо віддати папку на Netlify або Vercel, проксі налаштований у `_redirects`, `netlify.toml` і `vercel.json`. На GitHub Pages дані не підтягнуться, поки не виправлять CORS у самого API (нижче).

## Що вирішував по дорозі

**CORS.** Сервер freeserp.ai віддає заголовок `Access-Control-Allow-Origin` двічі (`*, *`), і браузер відхиляє такі відповіді з будь-якого сайту. Тому запити йдуть на `api/freeserp` того ж домену, а `server.js` (локально) або rewrite на Netlify/Vercel пересилає їх до API. Якщо проксі немає, застосунок пробує звернутися до API напряму, а в разі помилки пояснює причину в інтерфейсі. Для VS Code Live Server лежить `.vscode/settings.json` з проксі, але він не перевірений.

**Індекс відстає від сьогоднішньої дати.** Коли я дивився, найсвіжіший `went_live` був 8 вересня, а на календарі вже жовтень. Тож «новинки за 7 днів від сьогодні» були б порожні. Дата останнього оновлення береться з API, і період рахується від неї. Якщо дані відстають більше ніж на два дні, на сторінці та у футері про це написано. Відповіді кешуються на п'ять хвилин і оновлюються, коли повертаєшся до вкладки після довгої перерви.

**Ніші.** З `ai_startups=1` працюють лише ніші, які API вважає справжніми AI-продуктами. Решта категорій зі статистики (E-commerce, Productivity тощо) дають порожню видачу, тому в фільтрі вони не показані. Такі категорії все одно бувають у відповіді, тож у картках справжні ніші ставлю першими.

**Дата запуску.** `went_live` означає, коли зонд API вперше підтвердив, що сайт живий. Це не офіційна дата запуску, і в інтерфейсі я підписав її саме так.

## Як працював з AI

Користувався Claude Desktop. Спочатку прочитав документацію API та подивився реальні відповіді: саме так знайшов відставання індексу й сміттєві категорії. Далі генерував код частинами, перевіряв результат і правив. Помилки з консолі браузера та скріншоти мобільної й планшетної версій відправляв назад, за ними виправляв проксі й верстку. Прозорий навбар я забрав як нечитабельний, дизайн переробляв з окремою вимогою без емодзі й зайвих анімацій.

Логіку перевіряв автотестами (jsdom із підміненим API): фільтри, пагінація, порівняння, зміна дати індексу, тема, мобільне меню, фолбек без проксі. У репозиторій вони не потрапили, лишилися окремо. Верстку дивився в Chrome DevTools на мобільному й планшеті.

## Що не встиг

- Перевірити проксі й сайт на реальному деплої та в Safari.
- Сторінка деталей сайту, експорт порівняння, Open Graph для прев'ю посилань.
- Автотести в репозиторії й CI.
- Знімки в порівнянні не оновлюються: DR там на момент додавання сайту.

## Що доробив би далі

- Сторінка сайту з повним текстом (`content=1`) і схожими сайтами за нішею.
- Пошук по всьому вебу (`index=web`) для вибраного сайту: що про нього пишуть.
- Графік появи нових стартапів по днях і збережені пошуки.
- Англійська локалізація, збірка на Vite та тести на Vitest/Playwright.
